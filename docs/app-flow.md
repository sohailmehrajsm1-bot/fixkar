# FixKar App Flow (Updated)

## 1) Splash Screen

**FixKar – Local help for every home problem**

## 2) Login / Signup (Mobile OTP)

User enters phone number → OTP verification.

## 3) Select User Type

**“How do you want to use FixKar?”**

- 🔧 **I WANT TO WORK**
  - *(I am plumber, electrician, technician, helper etc.)*
- 🏠 **I NEED A WORKER**
  - *(I need someone to fix or help at home)*

This choice sends the user to different app flows.

---

# 🏠 Flow 1: “I Need a Worker” (Customer Side)

## Home Screen – “What problem do you have?”

Big problem buttons:

- 🚰 Water leakage
- ⚡ Electrical issue
- ❄ AC not cooling
- 🛠 Appliance repair
- 🧹 Need house help
- ➕ More

## Describe Problem

User can:

- ✍ Type issue
- 📷 Add photo (optional)

Button: **Find Nearby Workers**

## Worker List

Shows:

- Photo
- Rating ⭐
- Distance 📍
- Starting price 💰
- Availability 🟢

Buttons:

- 📞 Call
- 📅 Book Visit

## Booking Screen

Select date & time → Confirm.

## Rating Screen

After job → Rate worker.

---

# 🔧 Flow 2: “I Want to Work” (Worker Side)

## Worker Profile Setup

Worker fills:

- Name
- Photo
- Main Skill (Plumber / Electrician / AC etc.)
- Work Area
- Experience

Button: **Start Getting Jobs**

## Worker Dashboard

Shows:

- 🟢 Availability Toggle (ON/OFF)
- 📩 New Job Requests
- 💰 Earnings (later feature)

## Job Alert Screen

“New electrical job 2 km away”

Buttons:

- ✅ Accept
- ❌ Reject

## Job Details

Shows:

- Customer name
- Phone
- Address
- Problem description

Button: **Call Customer**

## Mark Job Complete

After work → Tap **Job Done**.

Customer gets rating screen.

---

# Why This Structure Is Powerful

- ✔ No confusion
- ✔ Workers don’t see customer features
- ✔ Customers don’t see worker dashboard
- ✔ App feels simple for both sides

This is how **Ola/Uber, Urban Company, Swiggy Partner** type apps work.
